# Image prompts

One prompt per breed, for Gemini or another image model. Every prompt shares the same style
sentence so the set looks consistent. Save each result as the file named under it (JPEG,
roughly 640 px on the long side is plenty); the app shows it in place of the Wikimedia photo.

The same prompts are in `image-prompts.csv` for batch use.

**Shared style:** Realistic professional pet photograph. One adult dog, whole body in frame, standing in a relaxed three-quarter view on short green grass in a quiet park. Soft natural morning light, camera at the dog's eye level, background gently blurred. Landscape 4:3. No people, no text, no watermark, no props, plain collar or none.
